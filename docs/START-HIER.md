# Ticketanzeige – kurze Anleitung für Kollegen

Auf dem Fernseher im Büro läuft unsere Ticketübersicht. Ein kleiner Debian-PC öffnet die Seite automatisch im Browser. Die Tickets selbst werden weiterhin im normalen Ticketsystem bearbeitet.

Im Alltag musst du am PC normalerweise nichts einstellen.

## Das Wichtigste

- **Anzeigezeiten:** vorgesehen ist Montag bis Freitag von 07:45 bis 17:30 Uhr.
- **Aktualisierung:** Die Ticketseite soll ungefähr jede Minute neu geladen werden.
- **Bearbeitung:** Tickets bitte am eigenen Arbeitsplatz bearbeiten, nicht über den gemeinsamen Fernseher.
- **Andere Inhalte:** Präsentationen oder Webseiten sind möglich. Danach wieder zur Ticketübersicht wechseln.

Der Fernseher und der PC sind zwei verschiedene Geräte. Auch wenn der Fernseher ausgeschaltet ist, kann der Tiny-PC weiterlaufen.

## Browser bedienen

| Aktion | Tastenkombination |
| --- | --- |
| Anderes Fenster öffnen | `Alt + Tab` |
| Vollbild ein- oder ausschalten | `F11` |
| Webadresse eingeben | `Strg + L` |
| Zur Ticketanzeige zurück | Ticket-Registerkarte im Browser auswählen |

Falls `F11` bei einer Fernwartung nicht funktioniert: Im Chromium-Menü (drei Punkte) neben **Zoom** auf das Vollbild-Symbol klicken.

Die automatische Aktualisierung ist für die Ticketseite eingerichtet. Andere Webseiten und Präsentationen sollen dadurch nicht unterbrochen werden.

## Wenn etwas nicht klappt

| Problem | Erst einmal prüfen |
| --- | --- |
| Fernseher bleibt schwarz | Ist er eingeschaltet? Stimmt die HDMI-Quelle? |
| „Kein Signal“ | HDMI-Eingang und Kabel prüfen. |
| Anmeldeseite statt Tickets | Der zuständigen IT Bescheid geben; keine fremden Zugangsdaten benutzen. |
| Tickets werden nicht aktualisiert | Etwa eine Minute beobachten. Bleibt die Ansicht stehen, IT informieren. |
| Präsentation ist noch zu sehen | Über `Alt + Tab` zur Ticketseite wechseln. |
| Fernsehbild oder Browser hängt | Fehlermeldung und Uhrzeit notieren, dann IT informieren. |

Den Tiny-PC bitte nicht einfach ausschalten oder neu einrichten. So vermeiden wir unnötige Unterbrechungen der Anzeige.

## Datenschutz

Auf dem Fernseher können Kunden- und Ticketinformationen sichtbar sein. Deshalb keine Fotos davon unkontrolliert weitergeben und keine Passwörter auf dem gemeinsamen Bildschirm eingeben.

**Interne Ansprechpartner und Dashboard-Adresse** gehören in die betriebliche Dokumentation oder ins Team-Wiki, nicht in dieses öffentliche Repository.
